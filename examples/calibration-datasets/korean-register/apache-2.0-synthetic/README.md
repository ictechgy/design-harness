# Synthetic UI controls

These small controls are project-authored and licensed under Apache-2.0. They
are not copied, translated, or adapted from IWSLT.

The controls exercise evidence buckets only: one terminal EF, multiple EF
endings, a non-terminal EF, noun-form fragments, and other no-EF text. Their
project register labels are test metadata and are never used to relabel the
IWSLT `formal|informal` records.
