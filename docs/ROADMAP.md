## v0.6.3 — Korean rendering maintenance and opt-in Kiwi morphology (RELEASED 2026-07-28)

The public release bundles the majority-Hangul `word-break: break-all` risk, the screen-reader-only spacing exclusion, and the bounded opt-in Kiwi morphology slice. The owner approved exact `kiwi-nlp@0.23.0` and this implementation on 2026-07-28. It does not change the parser-free default, schema, enum, report contract, or local-URL boundary.

1. **Explicit offline activation.** `audit` and `loop` accept `--kiwi-model-dir` only with `--copy` whose locale is `ko` or `ko-KR`. The CLI verifies the exact five-file Kiwi `0.23.0` `cong` profile before browser or output side effects; there is no discovery, download, vendoring, or implicit model path.
2. **Phase- and resource-bounded runtime.** Browser capture closes before one morphology worker re-verifies the profile, initializes Kiwi from the exact bytes hashed through those same safe file handles, analyzes the complete rendered-copy batch, and terminates. No flag means no load or provenance. Startup, analysis, shutdown, inventory count, item count, per-item length, and total text are bounded. Parser runtime failure emits one non-failing notice and never makes the audit partial; a missing, replaced, or changed explicit model fails the audit closed.
3. **One narrow heuristic check.** `josa-batchim-mismatch` covers only `은/는`, `이/가`, `을/를`, and `과/와` with exact raw-offset agreement, a `J*` token, exactly one adjacent noun interpretation, and a precomposed Hangul final syllable. Ambiguous, digit-, Latin-, symbol-, and non-noun cases skip. The official-pattern criterion remains a low-confidence heuristic `risk`; it can never emit a deterministic failure.
4. **Calibration without false model claims.** Synthetic good/bad fixtures cover all four pairs and negative controls. CI uses a deterministic injected token fixture with `realModelLoaded: false`; real model provenance is recorded only after successful worker analysis. The parser-free synchronous API and its five checks remain unchanged.
5. **License and packaging boundary.** `kiwi-nlp` is an exact copy-audit dependency and may be imported dynamically only by the dedicated worker. Its npm metadata declares LGPL-2.1-or-later while the upstream README describes LGPL v3; model files are external operator inputs. Dependency, static-import, model-asset, calibration-provenance, and package-boundary policies fail closed.

Release evidence includes `CI=true pnpm release:check`, browser smokes, an installed-tarball smoke, immutable review approval, and Ubuntu 24.04 x86_64 / Node v22.23.1 worker measurement. Three Ubuntu runs produced identical findings, completed in 1.51–1.63 seconds, reached 802,940 KiB maximum RSS with zero swaps, terminated successfully, and left no orphan process. The local macOS Node 22 probe remains implementation evidence only: same-handle model verification plus initialization reached about 792 MiB RSS, and three repeated analyses of the same batch completed in 632–661 ms with identical normalized output.
